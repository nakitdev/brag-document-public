# ตุลาคม 2026 (พ.ศ. 2569)

## สรุปเดือน

- ผลงานเด่น:
  - เปลี่ยนที่อยู่บริษัทบนเอกสารลูกค้าขึ้น prod ครบ 4 ระบบ (หน้าร้าน, ใบปะหน้า, หลังบ้าน, การเงิน) และยังเลือกใช้ที่อยู่เก่าได้สำหรับเอกสารย้อนหลัง
  - ใบปะหน้าของขนส่งรายใหม่ 2 ขนาดแรก (3 แบบแสดงสินค้า + เก็บเงินปลายทาง) โดยแยกส่วนบนเป็น helper ใช้ร่วมกันทุกขนาด
  - ตั้ง Claude Code ให้ใช้ skill ของทีมได้ พร้อม skill ส่วนตัวสำหรับเริ่มวัน/จบวัน/เรียนรู้ และ brag document นี้
- ตัวเลขที่วัดได้: PR merge 10 ตัว · unit test ของ service ใบปะหน้าเพิ่มจาก 203 เป็น 217 ข้อ · แก้ export Excel ไม่ให้พังเมื่อหาบัญชีไม่เจอ
- สื่อสารกับทีม (แจ้งก่อนถูกถาม): รวม 14 ครั้งใน 5 วัน แนวโน้มดีขึ้นชัดตอนท้ายเดือน
- ได้เรียนรู้: Claude Code (skill, plugin, memory, MCP, subagent, hook) · PDFKit ellipsis กับความสูงบรรทัด · แยกส่วนที่เหมือนกันเป็น helper แทน if ตามขนาด

### 2026-10-28 (พุธ)

**ทำอะไรไป**
- ทำใบปะหน้าขนส่งรายใหม่ขนาด 100x75 (โอนเงิน / เก็บเงินปลายทาง) ตามแบบ: แยกออกจากโค้ดของขนส่งเดิมเป็น module ของตัวเอง แล้ว merge เข้า develop
- ทำขนาด 100x100 ครบ 3 แบบแสดงสินค้า + เก็บเงินปลายทาง: หมายเหตุ 1–3 บรรทัด และจำนวนรายการสินค้าปรับตามพื้นที่ที่เหลือ (4/5/6 รายการ)

- ได้ไฟเขียวจาก BA ให้ deploy เรื่องที่อยู่บริษัท

**ผลลัพธ์ / impact**
- order ขนาด 75 ได้ใบปะหน้าของขนส่งเองบน beta ขนาดที่ยังไม่มีแบบยังพิมพ์ layout เดิมได้ ใบปะหน้าไม่พังระหว่างทยอยทำ

**สื่อสารกับทีม**

**ได้เรียนรู้**
- ข้อความใน PDFKit ที่ใส่ `height` + `ellipsis` จะตัดด้วย "…" ตั้งแต่บรรทัดที่เหลือพื้นที่ไม่ถึง 2 เท่าของความสูงบรรทัด ต้องเผื่อ `height` ให้เกินจำนวนบรรทัดที่อยากได้
- `qlmanage` เก็บ thumbnail ไว้ใน cache ตามชื่อไฟล์ ถ้า render ซ้ำด้วยชื่อเดิมจะได้รูปเก่า ต้องเปลี่ยนชื่อไฟล์ทุกรอบ
- เลือกแยกส่วนที่เหมือนกันเป็น helper แทนการรวมเป็นฟังก์ชันเดียวแล้ว if ตามขนาด: ไม่ซ้ำ และเพิ่มขนาดใหม่ได้โดยไม่ต้องแตะขนาดเดิม
