# Brag document — nakit (public)

บันทึกงานรายวันของ backend developer: ทำอะไร ได้ผลอะไร และได้เรียนรู้อะไร

ไฟล์นี้เป็นเวอร์ชัน public ของ brag document ส่วนตัว ตัดข้อมูลภายในบริษัทออกแล้ว ได้แก่ ชื่อบริษัทและลูกค้า ชื่อ repo, service และ infra ภายใน เลขการ์ด/PR และลิงก์ภายใน ชื่อเพื่อนร่วมงาน และค่า config ต่างๆ ส่วนที่เก็บไว้คือเทคนิค ตัวเลขผลลัพธ์ และบทเรียน

- หนึ่งไฟล์ต่อเดือน: `<ปี>/<MM>-<month>.md`
- stack ที่ใช้บ่อย: Node.js / TypeScript, NestJS, MongoDB, PDFKit, Jest, GCP, Kubernetes (GitOps), Claude Code

## โครงของแต่ละวัน

```markdown
### 2026-10-26 (จันทร์)

**ทำอะไรไป**
- ...

**ผลลัพธ์ / impact**
- ...

**สื่อสารกับทีม**
- ...

**ได้เรียนรู้**
- ...
```
